Privacy Policy

Last updated: October 24, 2026

AI Shorts is a private tool used only by the owner of a single YouTube channel to upload videos to that channel.

What it accesses

With the owner's permission, AI Shorts uses YouTube API Services only on the owner's own channel, to:

  • upload videos the owner's tool produced (YouTube Data API, youtube.upload);
  • read the titles and descriptions of the channel's recent uploads, so the same story is not covered twice (youtube.readonly);
  • read view counts and average watch time of the channel's own videos, to choose better topics (YouTube Analytics API, yt-analytics.readonly);
  • post the channel's own question as the first comment on its own public videos (youtube.force-ssl).

Analytics figures are read when needed and are not stored beyond the session that reads them. A local list of uploaded video IDs and titles is kept by the owner.

What it does not do

It does not collect, store, sell or share personal data of anyone. It does not access any other user's account, and it is not offered to the public.

Credentials

The access credentials are stored privately by the owner and are used only to make the requests described above. The owner can revoke access at any time at myaccount.google.com/permissions.

Google API Services

AI Shorts' use of information received from Google APIs adheres to the Google API Services User Data Policy. It also relies on YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

The owner can revoke AI Shorts' access at any time at myaccount.google.com/permissions or through Google security settings. After revocation no further data is read.
