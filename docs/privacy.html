Privacy Policy

Last updated: October 20, 2026

AI Shorts is a private tool used only by the owner of a single YouTube channel to upload videos to that channel.

What it accesses

With the owner's permission, AI Shorts uses the YouTube Data API to upload videos to the owner's channel and to read the titles of that channel's recent uploads, so that the same story is not covered twice.

What it does not do

It does not collect, store, sell or share personal data of anyone. It does not access any other user's account, and it is not offered to the public.

Credentials

The access credentials are stored privately by the owner and are used only to make the requests described above. The owner can revoke access at any time at myaccount.google.com/permissions.

Google API Services

AI Shorts' use of information received from Google APIs adheres to the Google API Services User Data Policy. It also relies on YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
